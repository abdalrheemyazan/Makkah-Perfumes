## 1. עיבוד נכסי מקור (בוצע)

### 1.1 המרת AVIF לבדיקה ויזואלית

הכלים הקיימים לא הצליחו להציג AVIF ישירות, ולכן נוצרו נגזרות PNG לצורך בדיקה
ויזואלית של כל 13 המוצרים לפני כתיבת קוד.

```bash
ffmpeg -y -i "<source>.avif" -vf "scale=420:-1" "<slug>.png"
```

תוצאה: כל 13 המוצרים נבדקו ויזואלית. הממצאים תועדו ב-[ASSET_MANIFEST.md](./ASSET_MANIFEST.md) §3.

### 1.2 נרמול ונגזרות ייצור

```bash
# העתקה ללא שינוי
cp "<source>.avif" public/brand-reference/products/<slug>.avif
# נגזרת PNG — קלט לכלי עיבוד שאינם קוראים AVIF
ffmpeg -y -i "<source>.avif" public/brand-reference/products/<slug>.png
# נגזרת WebP — גיבוי לדפדפנים ללא תמיכת AVIF
ffmpeg -y -i "<source>.avif" -c:v libwebp -q:v 92 public/brand-reference/products/<slug>.webp
# לוגו
ffmpeg -y -i logo.webp public/brand-reference/logo/logo.png
```

| פריט | ערך |
|---|---|
| קבצי מקור | 14 (13 מוצרים + לוגו) |
| קבצים שנוצרו | 39 מוצרים (13 × 3) + 2 לוגו |
| ערוץ אלפא | נשמר בכל הפורמטים |
| שינוי בתוכן התמונה | **אין.** רק המרת פורמט |
| גיבוי מקור | `assets/original-brand-reference/` — בייט-לבייט |

## 2. נכסים קולנועיים (Higgsfield) — לא בוצע

**סטטוס: לא נוצרו נכסים קולנועיים.**

`public/generated/` נוצרה על כל תת-התיקיות אך היא **ריקה**.

### כלים שנבדקו בפועל

שרת ה-MCP של Higgsfield מחובר. הופעלה בדיקת יכולות
(`models_explore` עם `action: 'recommend'`) והוחזר קטלוג מודלים אמיתי. המודלים
הרלוונטיים ביותר שזוהו — **לא נוסו בפועל**:

| מודל | סוג | רלוונטיות |
|---|---|---|
| `seedance_2_0` | וידאו | תומך `image_references` לשמירת זהות מוצר, `start_image`/`end_image`, עד 15 שניות, 1080p/4K, `generate_audio: false` לווידאו שקט |
| `nano_banana_pro` | תמונה | 4K, מתאים לקיפריים קולנועיים |
| `soul_2` | תמונה | תמונות עריכתיות מבוססות רפרנס |
| `marketing_studio_image` | תמונה | מוצרי מסחר |

**לא בוצעה אף קריאת ג'נרציה, ולא נצרכו קרדיטים.**

### מדוע לא בוצע

העדיפות ניתנה לבניית ליבת המסחר הפועלת (קטלוג, עגלה, תשלום, הזמנות, בדיקות)
על פני נכסים ויזואליים. ג'נרציה קולנועית דורשת מחזור של יצירת מועמדים, בדיקה
ויזואלית של כל אחד מהם מול קריטריוני הפסילה, ובחירה — תהליך ארוך שלא הושלם.

### מצב העמוד הראשי כיום

עמוד הבית **אינו מציג מדיה שבורה**. ה-hero בנוי מ:
- תצלום המוצר האמיתי (Royal Leather), ללא שינוי
- במה מוארת ב-CSS בלבד (`radial-gradient` בגווני ענבר)
- טקסט HTML אמיתי

הרכיב `src/components/home/hero-media.tsx` נכתב ונבדק בטיפוסים, ומוכן לקבל
`videoSrc` / `posterSrc` כשייווצרו. הוא כבר מממש: פוסטר תמיד קודם, ויתור על
וידאו במצב `prefers-reduced-motion` או `save-data`, השהיה מחוץ למסך, ונפילה
חיננית לפוסטר בכשל טעינה. הוא **אינו מחובר** לעמוד כרגע, כי אין לו מקור.
