# הדגמת בסיס הנתונים בכיתה — Makkah Perfumes

בסיס הנתונים המקומי הוא **PostgreSQL מוטמע** (ללא Docker, ללא התקנה מערכתית).
מיועד לפיתוח, בדיקות והדגמה בכיתה בלבד — אינו מסד הייצור. אין למחוק הזמנות או
משתמשים קיימים.

## פקודות מסד הנתונים

| פקודה | פעולה |
|---|---|
| `npm run db:server` | הפעלת PostgreSQL המקומי (פורט 55432). נדרש לפני `npm run dev` |
| `npm run db:studio` | פתיחת Prisma Studio (דפדפן טבלאות) |
| `npm run db:status` | סטטוס מיגרציות וחיבור (`prisma migrate status`) |
| `npm run db:backup` | גיבוי לוגי (JSON) של טבלאות הליבה אל `backups/` (קריאה בלבד; ללא סיסמאות) |
| `npm run db:migrate` | יצירת/החלת מיגרציה בפיתוח |
| `npm run db:deploy` | החלת מיגרציות בייצור (`migrate deploy`) |

## תסריט הדגמה (7–9 שלבים)

1. `npm run db:server` ואז `npm run dev`.
2. `npm run db:studio` — פתחו את טבלת **Product**, **Order**, **OrderItem**.
3. באתר: בית → מוצר → הוספה לעגלה → תשלום (מצב פיתוח) → אישור הזמנה.
4. רעננו את Prisma Studio — הרשומה החדשה מופיעה ב-**Order** וב-**OrderItem**.
5. התחברו כמנהל ופתחו "ניהול החנות" → **מלאי**.
6. עדכנו כמות מלאי של מוצר עם סיבה.
7. רעננו את טבלת **InventoryItem** / **InventoryMovement** — הכמות והתנועה עודכנו.
8. שנו סטטוס הזמנה בלוח הניהול (למשל: חדשה → בטיפול).
9. רעננו את טבלת **Order** — הסטטוס נשמר ומתעדכן גם לאחר רענון הדף.

> הדגמה זו מוכיחה שהמערכת כותבת וקוראת רשומות אמיתיות ב-PostgreSQL — לא מסך הצלחה
> מדומה.
